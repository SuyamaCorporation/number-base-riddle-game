# Number Base Conversion Riddle Challenge

A timed conversion challenge where a number is shown in binary, octal, or hexadecimal and you must type the decimal equivalent (or vice versa) within 15 seconds. A streak counter drives a progressive difficulty system: every 3 correct answers in a row bumps the level, increasing the size and range of numbers. Wrong answers reveal a step-by-step conversion explanation.

## Features

- 15-second countdown timer with color-shifting bar (green → yellow → red)
- Progressive difficulty: 8 levels scaling from 4-bit binary up to 12-bit hex conversions
- Streak-based scoring: points = streak + level, rewarding consistency
- Interactive bit-flip grid for binary questions (clickable hint showing decimal equivalent)
- Full conversion explanation shown on wrong answers (positional notation breakdown)
